# Project Reflection

The Study Group Crew worked well as a small, ordered pipeline: the Topic Researcher supplies a fixed evidence brief, the Quiz Maker turns its concepts into retrieval questions, the Explainer adds plain-language support, and the Fact-Checker checks the final statements against the same brief. Passing each stage's named artifact explicitly made it clear where every question and explanation came from. The generated guide also records the context links and actual LangChain tool calls, so the workflow is inspectable rather than hidden behind a single response.

The main limitation is that this implementation deliberately runs offline. Its agents use deterministic instructional logic and local, curated photosynthesis notes, not an LLM; this made the demo repeatable and usable without credentials, but it is not open-ended research and does not generalize to arbitrary topics. The fact checker uses a strict verbatim-evidence test, which is transparent but can reject a correct paraphrase and cannot assess scientific nuance beyond the local notes. The question and explanation templates also need authoring when a new concept is added.

If I extended the project, I would add more carefully cited topics and more question types, then test how the crew handles paraphrases and unsupported claims. I would optionally add a model-backed mode for wider research and adaptive explanations, while retaining the local mode as a reliable fallback and clearly labeling model-generated content. I would also preserve the same context links and verification step so added flexibility does not obscure provenance or lower factual quality.
